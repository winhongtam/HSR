# HSR / 機捷時刻查詢

## 直接讀取以下檔案，不要用 PDF 解析或上網搜尋

| 用途 | 檔案 | 結構 |
|---|---|---|
| 高鐵全車次時刻（南下＋北上） | `hsr_schedule.md` | Markdown 表格，每列一個車次 |
| 機捷雙向時刻（A1/A12/A13/A17/A18/A21/A22） | `airport_mrt_timetable.md` | 每站一節，按小時分鐘列出 |
| 高鐵票價、車種、生效日 | `hsr_timetable.md` | 12×12 票價表 |

> 路徑相對於 repo 根目錄。`hsr_schedule.md` 是從 `HSR.pdf` 預先萃取的結構化資料；不需要再開 PDF。

## 查詢步驟（標準流程）

1. **判讀使用者意圖**：起站、迄站、時間區間、方向（南下／北上）、是否需要轉乘機捷。
2. **時刻查詢用 `Read` 讀對應檔案**，再用文字過濾找符合條件的列。
   - 高鐵：南下表頭欄位順序是 `南港 台北 板橋 桃園 新竹 苗栗 台中 彰化 雲林 嘉義 台南 左營`；北上相反。
   - `─` 表示該車次跳過該站；篩選時起、迄兩欄都必須非 `─`。
   - 「行駛日」欄若為「每日」則每天行駛；否則只在標示的中文週幾行駛（一=週一 … 日=週日）。
3. **比對使用者要求的時間區間**（以起站發車時刻為主）。
4. **必要時加上轉乘**（見下節）。
5. **輸出表格**：車次、行駛日、起站時刻、迄站時刻；若有跳停或限定日，加備註。

## 機捷 ↔ 高鐵桃園轉乘速查

| MRT 站 | 站名 | 到 A18 高鐵桃園站 | 方向 |
|---|---|---|---|
| A1 | 台北車站 | ~36 分（直達 ~22 分） | 往中壢／機場 |
| A8 | 長庚醫院 | ~24 分 | 往中壢 |
| A12 | 機場第一航廈 | ~17 分 | 往中壢 |
| A13 | 機場第二航廈 | ~15 分 | 往中壢 |
| A14a | 機場旅館 | ~10 分 | 往中壢 |
| A15 | 大園 | ~7 分 | 往中壢 |
| A16 | 橫山 | ~5 分 | 往中壢 |
| **A17** | **領航** | **~5 分** | **往中壢** |
| A19 | 桃園體育園區 | ~3 分 | 往台北 |
| A20 | 興南 | ~6 分 | 往台北 |
| A21 | 環北 | ~9 分 | 往台北（A22 老街溪為終點） |

**轉乘緩衝**：A18 出閘到高鐵閘門步行 + 取票 + 月台至少 **8–12 分鐘**；保守估抓 **15 分鐘**。

實務公式：使用者離站時刻 + 機捷車程 + 15 分轉乘 ≦ 高鐵發車時刻

## 行駛日符號對照

| 符號 | 意義 |
|---|---|
| 每日 | 一二三四五六日 都行駛 |
| 一 / 二 / … / 日 | 只該週幾行駛 |
| 一二三四五 | 平日（週一至週五） |
| 六日 | 週末 |
| 五日 | 週五 + 週日 |
| 一二三四五六 | 週一至週六 |
