# 機場捷運時刻查詢

## 何時觸發

使用者詢問機捷（桃園機場捷運）班次／時刻／首末班／特定時段車次，且涉及以下站點之一：
- A1 台北車站
- A12 機場第一航廈
- A13 機場第二航廈
- A17 領航站
- A18 高鐵桃園站
- A21 環北站
- A22 老街溪站

關鍵字：機捷、桃園機場捷運、台北車站到機場、領航、環北、老街溪、高鐵桃園、第一航廈、第二航廈、A1/A12/A13/A17/A18/A21/A22 等。

## 使用方法

執行 `query.py`，從專案根目錄呼叫：

```bash
python3 .claude/skills/mrt-query/query.py --from <起站> --to <迄站> [--start HH:MM] [--end HH:MM]
```

起／迄站可以用 A 編號或中文名（例：`A17` 或 `領航站`）。

### 範例

```bash
# A21 環北站到 A17 領航站，全日班次
python3 .claude/skills/mrt-query/query.py --from A21 --to A17

# 領航站到台北車站，下午 14:00–15:00
python3 .claude/skills/mrt-query/query.py --from 領航站 --to 台北車站 --start 14:00 --end 15:00

# 高鐵桃園到台北車站，下午時段
python3 .claude/skills/mrt-query/query.py --from A18 --to A1 --start 12:00 --end 18:00
```

## 輸出說明

腳本會：
1. 自動判定方向（北上 / 南下）
2. 解析來源站該方向的所有班次
3. 標註車型（普通車 / 直達車 / 尖峰增停直達車★ / 尖峰跳站普通車◆ / 增開往機場▼）
4. 標註該班是否停靠目的地（✅ / ❌ / ⚠ 模糊）
5. 末尾顯示「可搭 N 班 / 排除 N 班」摘要
